# 🌦️ Weather App

A simple and responsive weather application built with **HTML, CSS, and JavaScript**, using a Weather API to fetch real-time weather data.

## ✨ Features
- 🔍 Search weather by city name
- 🌡️ Display current temperature and weather conditions
- 💧 Show humidity and wind speed
- 🌤️ Display weather icons
- 📱 Responsive and user-friendly interface
- ⚡ Fetch live weather data using API integration

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Weather API

## 🚀 Getting Started
1. Clone this repository.
2. Open the project folder in your code editor.
3. Configure your Weather API key if required.
4. Open `index.html` in your browser.

## 🎯 Purpose
This project demonstrates frontend web development, API integration, asynchronous JavaScript, and dynamic DOM manipulation.
